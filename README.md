# Voidly Probe Desktop App (historical)

This repository is an early download page. It contains no desktop application source or installer. Its former versioned download links are no longer current.

For current desktop builds and installation steps, use the [Voidly Desktop download page](https://voidly.ai/download). For probe participation, the served target list, and the risks of making network measurements, read the [Voidly Probes guide](https://voidly.ai/probes) before installing.

The desktop app includes VPN routing and network measurement tools. Installing it does not establish a VPN connection or prove that a measurement ran. The current download page describes the protections and setup steps for each operating system.
