# Voidly Probe Desktop App

[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Measure internet censorship from your system tray. A desktop GUI for the [Voidly Community Probe](https://github.com/voidly-ai/community-probe) — built with Tauri for macOS, Windows, and Linux.

## What It Does

- Tests connectivity to **62 websites** every 5 minutes from your network
- Detects DNS blocking, TCP resets, TLS/SNI filtering, and block pages
- Runs silently in your system tray
- Auto-updates when new versions are available
- Results feed into Voidly's global censorship intelligence network

## Features

- **System tray** — runs in background, minimal resource usage
- **Auto-update** — checks for updates and prompts to install
- **Privacy-first** — no browsing data collected, IP hashed (never stored raw)
- **Cross-platform** — macOS (Apple Silicon), Windows (x64), Linux (x64)
- **Open data** — all results published under CC BY 4.0
